WOMEN'S TECHNOVA 2K26 - TECH QUIZ APP

Files:
- index.html       -> main app screens
- styles.css       -> dark/neon design
- app.js           -> navigation, timer, scoring, question flow
- questions.js     -> quiz question bank
- aditya_logo.png  -> Aditya logo used in the header

HOW TO RUN:
1. Keep all 5 files in the same folder.
2. Double-click index.html.
3. The app opens in Chrome/Edge.

The app follows the provided screenshots:
Home -> General Rules -> Round Selection -> Round Rules -> Question Grid -> Question Stage.

NOTE: questions.js is the existing question bank supplied with the app. Edit that file to change questions/answers.
