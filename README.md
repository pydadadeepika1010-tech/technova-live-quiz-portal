 # ⚡ Women's Technova 2K26 - Interactive Tech Quiz Portal

An interactive, responsive on-screen stage quiz application designed and developed for the inter-campus **Women's Technova 2K26** festival at **Aditya Degree College for Women (Ramnagar, Visakhapatnam)**. 

This platform was used live on the main stage screen to conduct multi-round technical quiz battles for over 100+ participating students.

---

## 🌟 Key Features

* **Interactive Stage Display Grid:** Designed specifically for live stage presentations where participants pick question numbers on screen to reveal questions, options, and countdown timers.
* **Multi-Round Competition Engine:**
  * **Round 1:** Foundation & Computer Fundamentals
  * **Round 2:** Core Programming & Technical Logic
  * **Round 3:** Rapid Fire & Problem Solving
* **Cyberpunk / Glassmorphism UI:** Built with custom neon cyberpunk accents, smooth glassmorphism cards, and Google Fonts (`Orbitron`).
* **Live Interactive Effects:** Integrated with HTML5 Web Audio and Canvas Confetti for celebrations and audience engagement.
* **100% Client-Side:** Runs instantly in any modern web browser with zero server setup or complex dependencies required.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Glassmorphism & Neon Design System), JavaScript (ES6+)
* **Libraries:** Canvas Confetti API, Web Audio API
* **Branding:** Official Aditya Degree College For Women Logo & Badges
